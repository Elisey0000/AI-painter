## AI-painter

### Описание проекта

Китайская подвальная подделка "Quick, draw!"

### Как запустить сайт оффлайн?

1. Скачайте репозиторий себе на компьютер
2. Откройте папку с проектом в Visual Studio Code
3. Нажмите кнопку "Go live" в правом нижнем углу экрана и перейдите на локальный адрес компьютера(по умолчанию 192.168.1.1 или 192.168.1.0)

### Где найти сайт в интернете

Сайт лежит [**ТУТ**](https://elisey0000.github.io/AI-painter/)
